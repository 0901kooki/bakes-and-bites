# bakes & bites

Homepage for bakes & bites, a small home bakery in Pampanga selling cookies and treats baked to order. Orders go through Instagram at [@bakesnbitesbymik](https://www.instagram.com/bakesnbitesbymik/).

Plain HTML, CSS and JavaScript. No frameworks and no build step.

## Run it

Open `index.html` in a browser. That's it.

For live reloading while you edit, open the folder in VS Code and use the Live Server extension.

## What's in here

| File | What it does |
|---|---|
| `index.html` | The page content and structure |
| `css/styles.css` | All the styling. Brand colours, fonts and spacing are variables at the top |
| `js/main.js` | Builds the moving cookie rows in the hero and pauses them when they're off screen |
| `images/` | Cut-out product photos |

## Brand

- Colours: paper `#FAF5E9`, cream `#F0EFDB`, pink `#F5CBD7`, cocoa `#442F2A`, caramel `#C98A3C`, matcha `#7E8F5B`
- Type: Fredoka for headings, Figtree for body text, Courier Prime for prices and labels
- Every element has a 2px cocoa outline. Flat, no shadows.
